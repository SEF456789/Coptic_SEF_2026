# الحروف القبطية — Web App

تطبيق ويب بسيط (HTML/CSS/JS بدون build tools) فيه 3 تابات:

- **Tab 1 — الحروف**: شبكة الحروف القبطية الـ32. اضغط على أي حرف يشتغل صوت شرحه
  مع أنيميشن "بيشتغل صوت". اختَر شكل الخط من الأزرار فوق (ABRAAM / Avva Shenouda / Copt).
- **Tab 2 — لعبة الذاكرة**: كروت مقفولة بصورة مار أفرام السرياني من برا، وجوه
  كروت أسئلة وكروت إجابات، ولازم تطابق كل سؤال مع إجابته.
- **Tab 3**: فاضية حاليًا (placeholder "قريبًا").

## إزاي تشغّله

افتح `index.html` مباشرة في المتصفح، أو (أفضل، عشان تشغيل الصوت والصور
يشتغل صح مع بعض المتصفحات) شغّل سيرفر محلي بسيط من جوه الفولدر:

```bash
python3 -m http.server 8000
```

وبعدين افتح `http://localhost:8000` في المتصفح.

## فين تحط ملفاتك

```
coptic-app/
├── fonts/                          ← حط هنا: ABRAAM_0.ttf, Avva_Shenouda.ttf, copt.ttf
├── assets/
│   ├── images/
│   │   ├── mar-afram.jpg           ← صورة مار أفرام (ظهر كروت لعبة الذاكرة)
│   │   └── letters/                ← صور أشكال الحروف (اختياري)
│   └── audio/
│       └── letters/                ← ملفات صوت شرح كل حرف
├── js/
│   ├── data-letters.js             ← اسم كل حرف + مسار الصورة + مسار الصوت
│   └── data-memory.js              ← مسار صورة مار أفرام + أسئلة/إجابات اللعبة
```

### 1. الخطوط القبطية
حط الملفات الثلاثة جوه `fonts/` بنفس الأسماء دي بالظبط:
`ABRAAM_0.ttf`, `Avva_Shenouda.ttf`, `copt.ttf`.
هي متربطة أوتوماتيك في `css/style.css` (قسم `@font-face`).

### 2. مسارات الحروف (Tab 1)
افتح `js/data-letters.js` واملأ لكل حرف:
```js
{ char: "Ⲁ", name: "ألفا", imagePath: "assets/images/letters/alpha.png", audioPath: "assets/audio/letters/alpha.mp3" }
```
- لو سبت `imagePath` فاضية، هيتعرض شكل الحرف تلقائيًا بالخط القبطي المختار.
- لو سبت `audioPath` فاضية، الضغط على الحرف هيعرض أنيميشن التشغيل بس من غير صوت حقيقي (معاينة).

### 3. لعبة الذاكرة (Tab 2)
افتح `js/data-memory.js`:
- `CARD_BACK_IMAGE`: مسار صورة مار أفرام، مثال `"assets/images/mar-afram.jpg"`.
- `MEMORY_PAIRS`: عدّل/زوّد الأسئلة والإجابات براحتك، كل عنصر بيتحول تلقائيًا
  لكارت سؤال + كارت إجابة في اللعبة.
